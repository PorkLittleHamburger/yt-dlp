# yt-dlp 简体中文本地化

此目录包含构建 `yt-dlp` Windows 简体中文版所需的运行时本地化层。

本地化在 PyInstaller 启动阶段安装，不修改提取器、格式选择器、URL
解析、Cookie 处理或下载逻辑。这样可以把上游源码更新和翻译层分开，
减少自动同步时的代码冲突。

## 范围

- 命令帮助的选项说明、分组标题、用法和页脚。
- 下载、提取、合并、等待、警告和错误等常见运行状态。
- 当前版本的全部可见命令选项。
- 技术名称、格式代码、URL、文件名和站点原始报错保持原样，避免误译
  命令参数或用户数据。

设置环境变量 `YT_DLP_LANG=en` 可以临时禁用本地化，便于排查上游问题。

## 校验

```powershell
python localization/check_localization.py --require-complete
```

构建流程在发布前还会检查 `--help` 输出，并生成帮助文本、版本号和
SHA-256 校验文件作为发布附件。
